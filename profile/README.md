## LLM Usage

Just like blind cherry-picking, ArfoxOS avoids "vibecoded" stuff. 

* **No blindly pasted code:** Anything committed here is reviewed, tested, and fully understood manually.
* **Brainstorming & assistance:** LLMs are used to bounce ideas around, talk through problems, and help explore implementations.
* **Maintainable:** If a piece of code can't be maintained or explained without an LLM, it doesn't get pushed.
